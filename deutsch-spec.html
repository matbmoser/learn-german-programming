Sprachspezifikation · Deutsch · A2–B2

German is a typed language.

Every noun phrase carries a type signature — gender, case, number — and the article and adjective endings are just that signature, written down. Every sentence opens a bracket and must close it. There are far fewer rules than tables; this page gives you the rules, shows you the trace for every form, and then drills you until they compile without thinking.

Die Satzklammer · the sentence bracket

§1

Four cases = four argument slots

A German verb is a function, and its arguments are labelled by case rather than by position. That is why word order can move: the labels are glued to the nouns, not to the slots. 

// the verb declares which slots it takes
geben( NOM giver, DAT receiver, AKK thing )

  Der Mann  gibt  der Frau  den Schlüssel.
  Den Schlüssel  gibt  der Mann  der Frau.   // same meaning

// in English the slots ARE the positions, so this breaks:
//   "The key gives the man the woman."  ✗

Nominativ

wer? was?

The subject — who performs. Also the complement of sein / werden / bleiben.

Der Hund schläft. · Das ist ein guter Freund.

Akkusativ

wen? was?

The direct object — what is affected. The default object case, and the case after durch, für, gegen, ohne, um.

Ich sehe den Hund. · für den Freund

Dativ

wem?

The indirect object — the recipient or beneficiary. Also forced by mit, nach, von, zu, bei, aus, seit.

Ich helfe dem Hund. · mit dem Auto

Genitiv

wessen?

Possession and belonging. Increasingly replaced by von + Dativ in speech — learn it to read, not to chat.

die Farbe des Hauses · wegen des Wetters

Regel 1.1 — case is assigned, never chosen

Something upstream always assigns the case: the verb, a preposition, or the possessive relation. Find the assigner first, then decline. Never start from the noun.

Regel 2.1 — the ending is the type tag

-r ≈ masc.NOM / fem.DAT+GEN · -n ≈ masc.AKK / plural.DAT · -m ≈ DAT masc+neut · -s ≈ GEN masc+neut. The same four signals ride on der-, ein-, and adjectives alike.

§3

Adjective endings: one signal, marked exactly once

Learners memorise three 16-cell tables. You only need one conditional and two shapes. 

function adjektivEndung(artikel, genus, kasus) {
  // does the article already show the case+gender signal?
  if (!artikel)                 return STARK[genus][kasus];   // nothing there → adjective takes over
  if (artikel.endung === "")   return STARK[genus][kasus];   // "ein", "ein" → naked, adjective covers
  return                        SCHWACH[genus][kasus]; // signal already given → -e or -en
}

That is the whole system. The case-and-gender signal must appear exactly once in the noun phrase. If der/dem/den… already carries it, the adjective relaxes into the weak set. If the article is one of the three naked ein cells, or there is no article at all, the adjective picks up the signal itself and looks exactly like the der-word would have.

§4

Prepositions are case constants

Most prepositions hard-code their case — no thinking required once memorised. Nine of them take a boolean argument. 

const AKKUSATIV = [ durch, für, gegen, ohne, um, bis, entlang ];
// mnemonic: DOGFUB — durch ohne gegen für um bis

const DATIV     = [ aus, außer, bei, mit, nach, seit, von, zu, gegenüber ];
// these nine are the highest-frequency ones in the language — learn them first

const GENITIV   = [ wegen, während, trotz, statt, innerhalb, außerhalb ];
// in speech these often take Dativ instead: "wegen dem Wetter"

function WECHSEL(prep, bewegung) {   // an auf hinter in neben über unter vor zwischen
  return bewegung ? AKKUSATIV : DATIV;
}
Wechselpräposition · flip the boolean

The test is not "is there movement in the scene" but does the phrase describe crossing a boundary into the place. Ich laufe in dem Park — I am running around inside the park (Dativ). Ich laufe in den Park — I am running into it from outside (Akkusativ). Both have running.

Regel 4.1 — contractions are not new words

im = in dem · ins = in das · am = an dem · ans = an das · zum = zu dem · zur = zu der · beim = bei dem · vom = von dem. Expand them mentally and the case is visible again.

§5

Six tenses, two building blocks

German barely conjugates for tense. It composes: an auxiliary carries the person and the time, and a fixed non-finite form carries the meaning. Learn two forms per verb and all six tenses fall out. 

// you only ever memorise these two per verb:
Partizip II   essen → gegessen      Präteritum-Stamm  essen → aß

// everything else is composition
Präsens          = stamm + endung
Präteritum       = prät-stamm + endung
Perfekt          = haben/sein[Präsens]    + Partizip II
Plusquamperfekt  = haben/sein[Präteritum] + Partizip II
Futur I          = werden[Präsens]        + Infinitiv
Futur II         = werden[Präsens]        + Partizip II + haben/sein

haben or sein? Use sein when the verb has no direct object and describes movement from A to B (gehen, fahren, kommen, fliegen, laufen) or a change of state (aufstehen, einschlafen, sterben, wachsen) — plus the three lexical exceptions sein, bleiben, werden. Everything else takes haben. Roughly 95% of verbs take haben, so sein is the list worth learning.

Building Partizip II. Weak verbs: ge- + Stamm + -t (machen → gemacht). Strong verbs: ge- + veränderter Stamm + -en (sprechen → gesprochen). Drop the ge- when the verb starts with an unstressed prefix (be-, emp-, ent-, er-, ge-, miss-, ver-, zer-) or ends in -ieren: verstehen → verstanden, studieren → studiert. With a separable prefix the ge- slots into the middle: aufstehen → aufgestanden.

  • Präsens

    jetzt · und auch: die Zukunft
    Stamm + e/st/t/en/t/en
    Ich esse einen Apfel. · Morgen fahre ich nach Berlin.

  • Perfekt

    gesprochene Vergangenheit
    haben/sein + … + Partizip II
    Ich habe einen Apfel gegessen.

  • Präteritum

    geschriebene Vergangenheit
    Prät-Stamm + —/st/—/en/t/en · gesprochen fast nur bei sein, haben, Modalverben
    Er aß einen Apfel. · Ich war müde. · Wir hatten Zeit.

  • Plusquamperfekt

    Vergangenheit vor der Vergangenheit
    hatte/war + … + Partizip II
    Ich hatte schon gegessen, als du kamst.

  • Futur I

    Absicht, Vermutung, Versprechen
    werden + … + Infinitiv
    Ich werde einen Apfel essen.

  • Futur II

    fertig bis zu einem Zeitpunkt · selten
    werden + … + Partizip II + haben/sein
    Bis acht werde ich gegessen haben.

§6

Word order: open a bracket, close a bracket

German syntax has one governing shape. Once you see it, sentence-final verbs stop feeling random. 

// MAIN CLAUSE — the finite verb is locked to position 2
[ any one element ] [ finites Verb ] [ … Mittelfeld … ] [ Rest des Verbs ]
   ↑ subject, time, place, object — your choice, but exactly ONE

// SUBORDINATE CLAUSE — the conjunction takes slot 2, so the verb is pushed to the end
[ weil / dass / ob / wenn / obwohl / damit ] [ … ] [ Rest ] [ finites Verb ]

// Mittelfeld ordering, when nothing is emphasised:
TE-KA-MO-LO  =  Temporal → Kausal → Modal → Lokal
               (wann?)     (warum?)   (wie?)     (wo/wohin?)
Ich fahre heute wegen der Arbeit mit dem Zug nach Köln.

// two objects: DATIV before AKKUSATIV — unless the accusative is a pronoun
Ich gebe dem Kind das Buch.
Ich gebe es dem Kind.      // pronoun jumps the queue

Why the bracket matters. The two verb parts are the walls of a container, and everything else lives between them. That is why a German speaker can keep adding detail for ten seconds and still land the meaning at the very end — and why you must hold the opening auxiliary in memory until the closing participle arrives. Reading practice is bracket-matching practice.

Regel 6.1 — position 1 is a slot, not a subject

Put anything you want first, but the finite verb still comes second and the subject slides behind it: Heute fahre ich…, not Heute ich fahre…. The verb never moves; everything else does.
